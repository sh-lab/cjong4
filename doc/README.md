# cjong4 ドキュメント

このディレクトリには、cjong4 の設計を理解し、変更時の判断基準を共有するための文書を置きます。

## 文書一覧

- [アーキテクチャ概要](architecture.md): 現在の構成、責務、状態モデル、処理フロー、不変条件
- [v4.0.0の変更点と移行手順](releases/v4.0.0.md): 次期リリースのAPI変更、検証範囲、利用側の移行箇所
- [ADR](adr/README.md): 重要な設計判断と、その背景・結果

初めてコードを読む場合は、アーキテクチャ概要、関連するADR、公開ヘッダーの順に参照してください。READMEは利用方法の入口、このディレクトリは設計の詳細を記録する場所とします。

## 更新方針

- 現在の設計を説明する内容は `architecture.md` を更新します。
- 重要な設計判断を追加・変更する場合はADRを追加します。
- ADRで採用した内容を変更する場合、過去のADRを削除せず、新しいADRから置き換え関係を示します。
- コードと文書に差異が生じる変更では、同じ変更単位で文書も更新します。
